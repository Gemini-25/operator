# M1 — 지도: 블록 안의 이면 도로와 겹침 보장

공통 규칙은 `docs/specs/README.md`. **주 작업 폴더에서 한다**(다른 묶음은 이 파일들을 건드리지 않는다).

**자기 파일**: `src/sim/city.ts`, `src/sim/cityPlan.ts`, `src/view/city/staticCity.ts`, `src/view/city/places.ts`, `tests/sim.test.ts` 의 `건물마다 정해진 도시`.

문제: 설계도의 도로 50개(큰 블록) 길가에만 건물이 줄지어 있고, 블록 안쪽은 막다른 골목과 띄엄띄엄한 건물뿐이다. 긴 건물 밑으로 좁은 길이 지나가는 자리도 있다(지금의 검사는 상자의 아홉 점만 본다).

## 1. 이면 도로 (`city.ts` — `buildCity` 에서 도로 그래프를 만든 직후, `buildPlaces` 앞)

`function addLocalStreets(rng, nodes, edges): void`

1. **블록(면) 찾기** — 반변 순회. 교차로마다 나가는 간선을 각도(`atan2`)로 정렬한다. 반변 `(u→v)` 의 다음은, `v` 에서 `(v→u)` 바로 다음(시계 방향)의 간선. 모든 반변을 한 번씩 돌면 면이 나온다. 부호 있는 넓이로 바깥 면(가장 큰 것, 부호 반대)을 버린다. 막다른 길(차수 1)은 면 안에서 왕복으로 나타난다 — 넓이 계산에는 문제없다.
2. **나눌 면** — 넓이 > 55,000 이고, 무게중심이 뭍(`y < coastY(x) − 30`)·평지(`mountainAt < 0.25`)·강 밖(`riverDist > 40`)·호수 밖이고, `districtAt(cx, cy)?.density ≥ 0.5`.
3. **길 내기** — 면의 변 가운데 가장 긴 것 `e1`(고속도로·다리 제외). 그 가운데에서 면 안쪽 법선 방향으로 쏜 반직선이 처음 만나는 다른 변 `e2`(고속도로·다리면 포기). `e1` 위 `t1 ∈ [0.35, 0.65]`, `e2` 위의 만난 점 ± 15% 에 새 교차로 둘을 넣어 변을 쪼갠다(쪼갠 두 구간은 이름·등급·`road` 를 물려받고 `seq` 를 다시 매긴다). 두 교차로를 `cls: 'local'`, `speed` 는 `street` 의 0.8배인 구간으로 잇는다. 이름: `${e1.name} ${k}길`(k 는 그 도로에서 낸 순서).
   - 낼 수 없는 경우: 선분의 8등분 점 가운데 물·산(0.3 이상)·지도 밖이 있다 / 철길과 교차한다 / 손으로 놓은 건물(`LANDMARKS` 의 상자를 12 만큼 키운 것)과 닿는다 / 다른 도로와 교차한다 / 길이가 70 미만이거나 520 초과 / 새 교차로가 기존 교차로에서 45 안.
   - 길이가 260 을 넘으면 가운데에 교차로를 하나 더 두고 법선 방향으로 ±18 비튼다(직선만 늘어서지 않게). 비튼 뒤 위의 검사를 다시 한다.
4. **한 번 더** — 나뉜 면이 아직 70,000 보다 크면 같은 방법으로 다시(깊이 2 까지). 면은 매번 다시 구한다(그래프가 바뀌었으므로).
5. 새 교차로의 `district` 는 `districtAt` 으로, `key` 는 `L${n}`. `node.exit` 는 없다.

기대: 교차로 78 → 120~150, 이면 도로 구간 30~50, 건물 1,200 → 1,500~1,700. 수치는 테스트의 하한으로만 쓴다(20개 이상).

주의: `RoadEdge.arterial`·`cls` 로 그림과 속도가 갈린다. `local` 은 좁다(`roadHalf`). `nodeName`(교차로 이름)은 큰 도로 둘의 이름을 쓰므로 이면 도로끼리 만나는 곳도 이름이 나오는지 본다. 시설(`facilities`)의 `nodeId`, `EXITS`, 헬기·구조정의 길 밖 이동은 교차로 번호에 기대므로 **기존 교차로의 번호와 순서는 바꾸지 않는다**(새 교차로는 끝에 붙인다). 간선도 끝에 붙이되, 쪼개는 간선은 원래 번호를 앞 토막이 물려받는다.

## 2. 겹침을 수식으로 막는다 (`city.ts` `buildPlaces`)

- `rectSegDist(box, ax, ay, bx, by)`: 선분을 상자의 좌표계로 돌려 선분-직사각형 최소 거리(교차하면 0). 건물은 모든 도로 구간에 대해 `≥ roadHalf(e) + 2.5`, 골목 `≥ 5.5`, 철길 `≥ 8`. (도로는 공간 해시로 가까운 것만.)
- 물: 상자 둘레를 6 간격으로 표본 떠 `riverDist ≥ 7`, `y < coastY(x) − 8`, 호수 타원 밖. 터(공원·해변·활주로·부두·컨테이너 부두·강변)는 물가에 걸칠 수 있으므로 도로 검사만.
- 건물끼리: 지금의 분리축 검사(`obbHit`)에 여유 2.5(주택 3.5, 아파트 9, 공장 7).
- **손으로 놓은 건물도 같은 검사를 통과해야 한다.** 어기면 생성 중에 예외(이름, 무엇에 걸렸는지). 걸리면 `cityPlan.ts` 의 좌표를 고친다. 이면 도로는 랜드마크를 피해 나므로(1-3) 새로 걸릴 일은 없어야 한다.
- 순서: 이면 도로 → 랜드마크 놓기·검증 → 막다른 골목 → 길가 채우기(이면 도로 포함) → 블록 안쪽 채우기.

## 3. 그림 (`view/city/staticCity.ts`)

`local` 등급: 가장 좁은 포장(차선 표시 없음), 주택가에서는 살짝 밝은 회색. 이면 도로의 이름표는 확대(zoom ≥ 2.6)에서만. 고정 층 한 번 그리는 시간이 늘지 않는지(건물 수 증가) 본다.

## 4. 테스트 (`건물마다 정해진 도시`)

- 모든 건물 × 가까운 도로: `rectSegDist ≥ roadHalf`. 모든 건물 쌍(공간 해시의 이웃): 겹치지 않는다. 물 위·지도 밖 없음(터 제외). 랜드마크 포함.
- 도로끼리 교차하지 않는다(끝점 공유 제외). 모든 교차로에서 모든 교차로로 갈 수 있다. `local` 구간이 20개 이상. 건물의 85% 이상이 가장 가까운 도로에서 60 안.
- 지도가 교대마다 같다(지금 테스트 유지). 시설 14곳의 교차로가 유효하다.

## 5. 다시 재기

지도를 바꾸면 사건의 자리와 이동 시간이 달라져 모든 결과가 바뀐다. `npm run sweep -- 60`, 네 프리셋, 평균 대응 시간을 다시 재고, 범위를 벗어나면 `difficulty.ts`(사건 간격)·`resources.ts`(속도)에서 맞춘다. 수치는 합친 뒤 `README.md`·`ROADMAP.md` 에 적는다.
