## 설계와 다르게 한 곳

- Stage 4: defensive or aerial switches to interior on a planned transition once its condition has been gone for 3 s and interior is allowed ('<구역> 불길이 잡혔습니다. 안으로 들어가 마무리하겠습니다.', t.marr=true). The spec only had a planned transition after ventilate. Without it, fire success fell 4.8%p with 3 timeouts.
- Stage 4: defensive and aerial need a non-empty exteriorSpots or aerialSpots (geometry inside can). If the spot disappears during execution: switchMethod('tooFar') plus rememberFail for 60 s. This stopped 18 repeats of the start message.
- Stage 4: where X6 runs exterior ops (opsExterior), X6 runExterior goes first and R2 only records defensive or aerial when it finishes. R2's start message is suppressed there (announce returns -1).
- Stage 4: interior's air condition is R1 airShort (45 s) through gear.airLow, not 'scba > 60 s', so it matches fitFor and capableOf. aerialSpots lives in methods.ts so judgment and execution share it.
- Stage 4: fitFor suppress returns skills.fire when the agent has a hose and air is OK. Otherwise, if methodFit > 0, it returns skills.fire for a hose holder and 0.25 without a hose. The extinguisher runs before the pump check. With no hose and no method: finishTask 'nomethod'.
- Stage 5: optional work never widens the choice (widen = WORK_MODE[work] !== 'optional' in chooseMethod and methodFit). Otherwise the only method that had just been dropped (sniper) was re-picked every tick.
- Stage 5: beanbag and sniper are picked on the first arrival tick and then once a second while no method is set, and only for agents with that kit.
- Stage 5: the sniper's failure memory is rememberFail 'failed' (60 s), not the spec's a.mfail 15 s. This also applies when the target is out of sight three times from the spot. R3 fireRound does not exist yet, so sniper rounds are unlimited, which the spec allows.
- Stage 6: ventFirst's sense check (gas > 0.6) runs in the arrival recheck when the agent first reaches the valve, not the room door. After choosing, the agent goes to the door, installs, then returns to the valve.
- Stage 6: announce is chosen when the agent first reaches the perimeter spot, not when the task is assigned. The world rule also requires a.spot >= 0.
- Stage 6: rush's 'unit with seats left' counts only units assigned to the incident, onscene, and without a boardOrder.
