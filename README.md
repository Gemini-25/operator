# AUTONOMOUS RESPONSE

자율형 긴급구조 조직 시뮬레이션. 경찰·소방·구급 AI 조직이 가상의 도시에서 스스로 신고를 받고, 판단하고, 출동하고, 현장에서 협력하고, 실패하고, 다시 시도한다. 플레이어는 지휘관이 아니라 **관찰자**다. 화면에는 AI에게 명령을 내리는 조작이 하나도 없다.

- 브라우저에서만 실행된다. 서버, 외부 API, LLM 호출이 없다. TypeScript + React + Vite, 그림은 Canvas 2D.
- 같은 시드와 같은 난이도로 실행하면 같은 교대가 그대로 재현된다. 되감기도 이 성질로 구현했다.
- 사건 유형 8가지: 건물 화재(단층·2층), 교통사고(버스 추돌 같은 다수 사상자 사고 포함), 실종·조난, 무장 사건(대치·총격·인질), 응급 환자, 건물 붕괴, 가스 누출, 수난 사고. 여기에 허위·오인 신고와 비긴급 전화가 섞인다.
- **설계된 도시 하나.** 격자가 아니다. 중앙광장 로터리에서 여섯 갈래로 퍼지는 구도심과 두 겹의 순환로, 강과 다리 다섯 개, 바다(해수욕장·항구·등대), 산(호수와 댐·사찰·터널), 비스듬히 놓인 신도시, 도시고속도로와 공항, 철길과 역, 막다른 길이 있다. 큰 도로가 만든 블록 안쪽에는 이면 도로 81구간이 나 있어 차량이 건물 앞까지 들어간다. 건물과 터 약 1,250곳에 종류·이름·주소가 있고 도로를 따라 비스듬히 놓이며, 도로·골목·철길·다른 건물과 겹치지 않는다(테스트가 모두 확인한다). 동네마다 성격이 다르지만 경계에서는 섞이고, 기차역·경기장·대학·백화점·성당·사찰·발전소·교도소처럼 하나뿐인 건물이 곳곳에 있다. 사건은 유형에 맞는 건물에서 일어나고(은행 강도는 은행에서, 수난 사고는 강·바다에서) 현장도 그 건물을 따른다.
- **사건의 모습이 여러 가지다.** 같은 유형 안에서도 시나리오가 갈린다. 시나리오마다 신고 내용, 일어나는 곳, 현장의 생김새, 보내는 부대가 다르다.
  - 생활 사건: 버스 추돌, 쓰러진 나무로 막힌 도로, 맨홀 추락, 승강기 갇힘, 가정 폭력, 침입 절도.
  - 강력 범죄: 강도·난동·총격·인질극·납치에 더해 폭발물(진짜 장치·폭파 협박·수상한 물건, 폭발물 처리반의 해체), 총 든 용의자 여럿이 인질을 방 둘에 나눠 잡는 대형 인질극, 폭동, 목격자를 놓치면 근처에서 또 불이 나는 연쇄 방화, 달아난 강도의 도주 차량, 납치범의 은신처.
  - 대형 사고: 비행기 추락, 열차 탈선, 고속도로 다중 추돌, 가스 폭발, 공사장 크레인 붕괴, 선박 화재. 교대마다 많아야 한 번 일어나고, 부대 예닐곱에서 열 팀이 한 현장에 모인다.
- **재난.** 태풍·홍수·지진·산불·해일 가운데 하나를 교대 시작 전에 고르거나 무작위(드물게)로 둔다. 특보 → 충격 → 여파의 단계로 진행되며 도시 여러 곳에 사건이 한꺼번에 나고 도로가 막힌다: 홍수는 강가의 길과 다리가 차례로 잠기고, 산불은 불머리가 산에서 동네로 번지며, 해일은 경보 뒤 해안 대피 현장을 물이 덮친다.
- **교통.** 정체는 한 구간에 머물지 않고 이웃 구간으로 밀린다. 공사·고장 차량·낙하물·행사 인파가 길을 막고, 골목의 불법 주차는 큰 소방차만 못 지나가게 한다. 아직 알려지지 않은 장애물은 부대가 가서 보고 무전으로 알린 뒤 되돌아 우회한다(관제는 알려진 도로 상태로만 경로를 짠다). 철길 건널목 여섯 곳에는 열차가 지나가고, 차단기가 내려가면 부대가 기다린다.
- **현장이 부서진다.** 총격과 폭발, 불의 열에 창이 깨지고, 엄폐하던 가구가 닳다가 부서져 엄폐물이 사라진다.
- **무너진 것이 한눈에 보인다.** 무너진 구역은 내려앉은 음영·높낮이 있는 잔해 더미·쓰러진 벽과 철근·금 간 벽·흙빛 점선 경계로, 무너지는 순간은 그림자·떨어지는 덩어리·먼지 기둥·충격 고리와 흔들림으로 그린다. 2차 붕괴가 날 수 있는 구역에는 위험 범위와 진행 고리가 뜨고, 밤에도 어둠 위에 보인다. 지도에서는 무너진 건물의 지붕에 구멍과 잔해·먼지가 생기고, 사건 카드에는 '일부/크게 붕괴'·균열·가스 고임·인질 같은 상태 칩이 붙는다. 가스가 고인 범위, 꺼진 줄 알았다가 되살아난 불, 폭발 자국, 인질의 상태(붙잡힘·창가·감시·갇힘·풀려남)도 표시한다.
- **교전이 보이고 들린다.** 총구 섬광과 예광선(대원은 푸른빛, 용의자는 주황), 벽·문·가구의 탄착, 날아가 터지며 방을 채우는 섬광탄, 반경에 따라 커지는 폭발과 흔들림, 동시 진입의 3-2-1 신호와 튕겨 열리는 문짝, 겨누는 선과 협상 말풍선, 검거의 수갑. 소리는 무기마다 다르고 거리·좌우에 따라 달라지며, 배속이 높아도 몰리지 않게 묶는다. 첫 발과 진입 직전에는 저절로 1배속이 된다. 지도에서는 교전 중인 사건 핀에 별과 점선 테가 뜬다. 피는 그리지 않는다.
- **추격전.** 납치 차량과 난폭 운전 차량은 도로망을 실제로 달린다. 관제는 시민의 목격 신고와, 따라붙은 순찰차·헬기의 시야로만 위치를 알고, 출동한 부대는 그 위치로 계속 방향을 바꾼다. 순찰차가 바짝 붙어 버티거나 앞질러 교차로를 막으면 차가 서고 그 자리에 현장이 열린다. 놓치면 도시 밖으로 빠져나간다.
- **출동 조직은 네 분야.** 경찰·소방·구조·구급·특수에 3~6팀씩, 보통 난이도에서 19팀·대원 63명이다. 특수 분야에는 경찰 특공대, 소방 헬기, 화학 구조대, 구조정(해안을 따라 바다로 간다), 폭발물 처리반(장치를 해체한다)이 있다. 지도와 부대 목록에서 부대는 글자가 아니라 **그림 기호가 든 둥근 표식**으로 보인다(분야는 바탕색, 종류는 기호, 같은 종류 안의 번호는 아래의 점, 상태는 테).
- **부대마다 편성이 다르고, 대원마다 든 장비가 다르다.** 모든 부대가 2인 1조가 아니다: 순찰차 2명, 기동 순찰차 3명, 펌프차 4명(진압 팀장·관창수·진입대원·기관원), 사다리차 3명, 구조 공작차 5명(팀장·유압 구조대원 둘·탐지·로프), 구급차 2~3명, 특공대 5명(팀장·방패수·파괴 진입대원·진입대원·저격·관측수), 화학 구조차 4명, 폭발물 처리반 3명, 구조정 3명, 헬기 3~4명. 역할 36가지마다 능력과 기본 장비가 다르고, **장비가 맡을 수 있는 일을 정한다** — 공기호흡기를 멘 대원만 불·가스·붕괴 건물 안에 들어가고, 관창을 든 사람만 물을 쏘고, 해체 공구를 든 처리 요원만 폭발물을 해체한다. 열화상 카메라는 연기 속 시야를, 탐지 장비는 매몰자 발견을, 유압 구조기는 구출 속도를, 테이저는 흉기를 든 상대의 제압을, 방패와 조끼는 방호를, 제세동기와 의사 장비는 위중 환자의 처치를 바꾼다. 공기통은 연기 속에서 줄어 대기 지점에서 바꿔야 하고, 섬광탄·테이저는 개수가 사람 몫이며, 개인 장비 일부는 고장 난 채 교대를 시작해 처음 쓰려는 순간에야 드러난다. 조종사·정장·관측관은 현장에 내리지 않는다. 현장 그림에서는 역할마다 복장과 손에 든 것이 다르고, 부대 목록에는 대원마다 역할 기호가 든 점이 보인다.
- **헬기 세 종류.** 경찰 헬기(중부경찰서)는 추격전의 도주 차량을 하늘에서 쫓고, 무장·실종 현장 상공에 머물며 열영상으로 살피고 밤에는 탐조등을 비춘다. 소방 헬기(소방항공대)는 물 위의 사람을 호이스트로 끌어올려 병원으로 옮기고, 산불에는 물 바구니로 물을 뿌리고 다시 뜨러 다녀오며, 그 밖의 현장에는 내려앉아 구조대원이 일한다. 의료 헬기(가온대학교병원)는 낮에만 뜨고, 내려앉아 의사와 간호사가 위중 환자를 처치한 뒤 한 명을 싣고 날아간다. 안개 낀 날에는 어느 헬기도 뜨지 못하고, 태풍의 강풍이 닥치면 돌아오며, 체공 시간이 모자라면 복귀한다. 상공 도착은 '현장 도착'으로 세지 않는다(대응 시간은 지상 대원이 내린 때 기준이다).
- 건물 안의 방 배치(복도형·방 연결형·홀형·2층)는 사건마다 새로 만들어진다.
- 현장은 위에서 내려다본 건축 도면 방식으로 그린다: 두께 있는 벽과 그림자, 바닥 재질, 가구, 제복을 입은 인물, 차량, 화염·연기·물줄기, 야간 조명과 날씨.

이어서 개발할 사람(또는 AI 세션)은 `CLAUDE.md` 와 `docs/ROADMAP.md` 부터 읽는다.

## 설치와 실행

Node.js 20 이상이 필요하다.

```bash
npm install
```

```bash
npm run dev
```

브라우저에서 `http://localhost:5173` 을 연다. 주소 뒤에 `?seed=원하는글자` 를 붙이면 그 시드로, `&diff=hard` 나 `&diff=4,4,4,2,3,3`(일곱째 숫자를 붙이면 교통 상황)을 붙이면 그 난이도로, `&disaster=flood`(none · random · typhoon · flood · quake · wildfire · tsunami)를 붙이면 그 재난으로 시작한다. `&force=armed/bomb` 처럼 `유형/변형`을 붙이면 그 시나리오가 교대 초반에 한 번 일어난다(확인용).

| 명령 | 하는 일 |
|---|---|
| `npm run build` | 타입 검사 후 정적 파일을 `dist/` 에 만든다 |
| `npm test` | 자동 테스트 254개 + 건너뜀 1 (파일 12개: 기본 · 확장 지점 · 강력 범죄 · 대형 사고 · 재난 · 현장 파손 · 교통 · 측정 도구 · 교전 연출 · 반복 고리 · 현장 가독성 · 편성·장비·헬기) |
| `npm run check` | 타입 검사 + 테스트 + 시드 40개 헤드리스 검증 (커밋 전 관문) |
| `npm run sweep -- 100` | 화면 없이 시드 100개를 돌려 결과 분포와 교착 여부를 본다 (`--diff hard`, `--disaster quake`, `-v`, `--json`) |
| `npm run sweep -- 20 --force fire/plane --scen` | 그 시나리오를 교대마다 한 번 일으켜 시나리오별 결과 표를 낸다 |
| `npm run sweep -- 1 --log S7` | 시드 S7 한 교대의 전체 기록과 종료 보고서를 출력한다 |

## 조작 (관찰 전용)

| 조작 | 기능 |
|---|---|
| `Space` | 일시정지 / 재개 |
| `1` `2` `3` `4` | 1배속 / 3배속 / 8배속 / 15배속 |
| `←` `→` | 10초 되감기 / 앞으로 |
| 타임라인 클릭 | 그 시각으로 이동 (되감기 포함) |
| 기록 더블클릭, 보고서의 "결정적 순간" | 그 장면으로 돌아가 1배속으로 다시 본다 |
| `A` / `C` | 자동 카메라 / 도시 전체 보기 |
| `T` | 관찰자 시점 ↔ AI 시점 |
| `M` | 소리 켜기 / 끄기 |
| `S` | 자동 감속 켜기 / 끄기. 관찰 중인 현장에서 총격·폭발·진입이 벌어지면 잠깐 1배속으로 낮춘다 |
| `Z` | 현장 자동 확대 켜기 / 끄기. 카메라가 현장에서 벌어지는 일을 따라간다 |
| 지도의 사건 핀, 작은 현장 창 클릭 | 그 현장을 확대해서 본다 |
| 사건 카드·기록·타임라인의 사건 막대 클릭 | 그 사건으로 관찰 대상을 고정한다 |
| 현장의 대원, 부대 목록의 이름·역할 점 클릭 | 그 대원의 역할과 든 장비(수량·남은 공기·고장), 아는 정보, 행동 후보 점수, 인지 범위를 본다 |
| 현장 상공의 헬기 클릭 | 그 헬기의 관측자가 아는 정보와 헬기가 하는 일(상공 감시 · 호이스트 인양 · 물 투하 · 남은 체공 시간)을 본다 |
| 지도에서 휠·드래그 | 확대/축소, 이동. 가까이 보면 건물 이름과 골목 이름이 나타난다 |
| 지도의 건물·도로에 마우스 올리기 | 이름, 종류, 주소, 층수, 그곳에서 난 사건을 보여 준다 |
| 현장 화면에서 휠·드래그·더블클릭 | 확대/축소, 이동, 자동 확대로 되돌리기 (시점만 바뀐다) |
| 종료 보고서의 "주요 장면 이어 보기" | 그 교대의 결정적 순간들을 차례로 다시 본다 |
| 상단의 `난이도` 버튼 | 다음 교대의 조건(손잡이 일곱 개, 재난)을 정한다 (진행 중인 사건에는 영향 없음) |
| 지도 왼쪽 아래의 `범례` | 표식의 뜻을 펼쳐 본다 (부대 기호, 상태 테, 대원 역할 기호, 시설, 도로 색, 장애물) |

**관찰자 시점**에서는 AI가 아직 모르는 사실(발견되지 않은 구조 대상, 숨은 용의자, 미확인 연료 누출, 무전 음영 구역, 신고 내용의 사실 여부, 잘못 신고된 위치, 아직 아무도 모르는 길 위의 장애물, 아직 드러나지 않은 장비 고장)이 함께 보인다. **AI 시점**에서는 AI가 아는 것만 보이고, 무장 사건 현장은 대원이 지금 보고 있는 곳만 밝다.

## 난이도

난이도는 교대가 **시작되기 전에** 정하는 조건이다. 사건이 벌어진 뒤에는 아무것도 바꿀 수 없다. 손잡이 일곱 개(각 1~5, 3이 기준)와 프리셋 네 개가 있다.

| 손잡이 | 바꾸는 것 | 1일 때 → 5일 때 성공률 (나머지는 3) |
|---|---|---|
| 사건 빈도 | 사건 사이 간격, 교대당 사건 수(9~22건), 동시 진행 수(3~8건) | 84% → 67% |
| 사건 심각도 | 규모 분포, 숨은 위험, 부상 악화 속도, 화재 확산 속도 | 88% → 64% |
| 용의자 위협 | 무장 사건 비중, 총격범 비중, 용의자 수·공격성·사격 실력, 숨은 공범, 도주 시점 | 75% → 73% (아래 참고) |
| 대원 장비 상태 | 차량 주행 속도, 펌프·용수·구조·의료·방호 장비, 섬광탄 수, 출근 시 체력, 개인 장비의 고장 확률(12% → 0.5%), 공기통 용량(220초 → 320초) | 73% → 81% |
| 신고 신뢰도 | 침착한 신고자 비율, 위치를 틀리게 말할 확률, 허위 신고·비긴급 전화 빈도 | 71% → 76% (아래 참고) |
| 부대 규모 | 출동 부대 수 12 · 15 · 19 · 21 · 22팀(네 분야에 3~6팀씩)과 인원(1·2 는 최소 인원 — 펌프차 3명, 구조대 4명, 특공대 4명 …, 3 이상은 표준 인원. 대원 수 32 · 39 · 63 · 71 · 75명), 인근 도시 지원 횟수 2 · 2 · 3 · 4 · 5회. 경찰·의료 헬기는 3 부터 있다 | 60% → 81% |

위 손잡이 표는 손잡이마다 시드 30개로 잰 것이다. **대원 장비 상태와 부대 규모 두 줄은 부대 편성·개인 장비·헬기(R1)를 합친 뒤(2026-11-15)에 다시 쟀고**, 나머지 네 줄은 새 사건 묶음(강력 범죄·대형 사고·교통)을 합치기 전의 값이다. 일곱째 손잡이 **교통 상황**(도로의 교통량, 정체·공사·고장 차량·낙하물의 빈도, 골목의 불법 주차)은 이 표에 넣지 않았다. 아래 프리셋 표는 R1 을 합친 뒤에 다시 쟀다. 두 손잡이는 전체 성공률만으로는 차이가 잘 드러나지 않는다.

- **신고 신뢰도**는 성공률보다 과정을 바꾼다. 1에서는 허위 신고가 열 배 가까이 많고(29건 대 3건), 위치를 틀리게 신고받은 사건이 140건 생기며(5에서는 0건), 실제 사건의 평균 대응 시간이 9초 길다(54초 대 45초). 허위 신고는 확인만 하면 "성공"으로 끝나기 때문에 전체 성공률의 차이는 작다.
- **용의자 위협**은 무장 사건의 수와 난도를 바꾼다. 1에서는 무장 사건이 47건이고 그중 89%가 성공으로 끝나지만, 5에서는 94건으로 늘고 성공은 66%로 떨어진다. 다른 유형에는 영향이 없어 전체 성공률의 차이는 작다.

프리셋별 결과(시드 60개):

| 프리셋 | 손잡이 | 사건/교대 | 성공 | 부분 성공 | 대응 지연 | 미해결 | 실패 | 구조율 |
|---|---|---:|---:|---:|---:|---:|---:|---:|
| 쉬움 | 2-2-2-4-4-3 | 11.2 | 88% | 6% | 2% | 1% | 3% | 96% |
| 보통 | 3-3-3-3-3-3 | 14.1 | 81% | 9% | 4% | 2% | 4% | 94% |
| 어려움 | 4-4-4-2-2-3 | 18.4 | 63% | 15% | 6% | 4% | 12% | 87% |
| 극한 | 5-5-5-1-1-3 | 23.2 | 36% | 18% | 12% | 6% | 29% | 75% |

한 현장에는 같은 부서의 부대가 여러 팀 들어갈 수 있다(예: 경찰 2 + 소방 2 + 구급 1). 몇 팀이 들어갈지는 배정 AI의 판단과 현장 지휘관의 지원 요청으로 정해지며 상한은 없다. 기본 편성(19팀)의 시드 60개 실행에서는 한 사건에 최대 10팀이 들어갔다(대형 사고). 가용 부대가 없어 30초 넘게 밀린 수요가 있으면 **인근 도시 지원 부대**가 도시 밖으로 이어지는 길 다섯 곳 가운데 가장 가까운 데서 들어온다(사건당 한 번, 교대당 2~5회). 임무를 마치면 관할로 돌아간다.

출동 시설은 소방서 네 곳(중앙·서부·한솔·공단), 경찰서 세 곳(중부·서부·동부), 병원 두 곳(시립병원·가온대학교병원), 소방항공대(소방 헬기), 해양구조대(구조정)다. 경찰 헬기는 중부경찰서 옥상에, 의료 헬기는 가온대학교병원 옥상에 선다. 구급차는 더 빨리 닿는 병원으로 가고, 헬기는 병원 옥상의 착륙장에 내린다.

## 화면 구성

- **위**: 시각, 날씨, 교통 요약(원활 / 정체 n / 극심 n · 통제 n), 시드, 난이도와 재난.
- **왼쪽**: 진행·종료 사건(유형, 위험도, 배정 부대, 부족한 자원, 대형 사고 딱지), 네 분야로 묶은 출동 부대와 대원의 상태. 부대는 지도와 같은 표식으로 보이고, 대원은 부대장의 이름 칩과 **역할 기호가 든 점**으로 보인다(아래 반 테가 건강 색, 쓰러지면 빨간 테, 내리지 않는 자리는 점선 테). 점에 마우스를 올리면 이름·역할·장비·체력이 나온다.
- **가운데**: 도시 관제 지도 또는 현장 확대 화면(휠로 확대). 지도에는 도시 전체가 한눈에 들어온다. 멀리서는 도시에 하나뿐인 건물과 출동 시설의 이름만 보이고, 확대할수록 은행·호텔·상점의 이름이, 더 가까이 가면 골목 이름까지 나타난다. 주택은 마우스를 올려야 보인다. 지도 위의 표식은 모양으로 갈린다: **원은 부대**(그림 기호가 든 둥근 돌), **둥근 네모는 시설**(옆의 숫자는 대기 중인 부대 수), **고리 달린 핀은 사건**(대형 사고는 주황 고리가 하나 더 퍼진다). 일반 차량은 그리지 않고, 교통은 도로 위의 띠(노랑 서행 · 주황 정체 · 빨강 극심)와 붉은 점선(통제), 장애물 표식(공사·고장 차량·낙하물·불법 주차), 지나가는 열차와 내려간 차단기로 보인다. 헬기 세 종류는 지도 위를 곧장 날고(같은 윤곽, 분야색으로 갈린다) 구조정은 해안을 따라 간다. 현장 화면에서는 상공에 머무는 헬기가 그림자와 함께 떠 있고, 호이스트 줄과 매달린 구조대원, 물 바구니와 떨어지는 물 띠, 밤의 탐조등 원이 보인다. 대원은 역할에 따라 복장(흰 헬멧에 붉은 띠의 팀장, 주황 조끼의 기관원, 흰 가운의 의사, 부피 큰 방호복의 폭발물 처리 요원, 구명조끼의 수난 구조대원)과 손에 든 것(소총·저격 소총·방패·테이저·열화상 카메라·할리건·유압 구조기·큰 응급 가방·제세동기)이 다르고, 공기가 60초 아래인 대원의 머리 위에는 주황 점이 뜬다. 재난이 있으면 지도에 그 모습(불어난 강, 산불의 탄 자리와 불머리, 해일의 물마루, 정전의 어둠)이 그려지고 가운데 화면 위에 특보 띠가 뜬다. 통화 중에는 신고 통화창이, 결정적인 순간에는 속보 띠가 뜬다. 오른쪽 아래에는 도시 지도와 진행 중인 다른 현장이 작은 창으로 보이고, 왼쪽 아래의 `범례` 를 누르면 표식의 뜻이 펼쳐진다.
- **오른쪽 위**: 판단 요약(신고 정보 → 상황 분석 → 배정 → 현장 지휘관의 작업 목록 → 문제와 복구) 또는 대원 정보.
- **오른쪽 아래**: AI 관제·무전 기록.
- **아래**: 되감기·배속 제어, 자동 감속·자동 확대 켜기, 교대 진행 시간, 사건 타임라인, 소리.
- **교대 종료 시**: 사건별 결과와 원인 설명, 결정적 순간 목록, 교통으로 인한 지연, 대형 사고와 재난 대응 요약, 헬기 요약(종류별 출동·호이스트 인양·물 투하·공중 이송·연료 복귀, 뜨지 못한 까닭), 다친 대원의 역할이 담긴 보고서. 주요 장면을 차례로 이어 볼 수 있다.

### 한 사건의 흐름

1. **사건 발생**: 생성기가 유형·규모·숨은 위험을 정하고, 지도에서 그 유형에 맞는 건물을 고른 뒤 그 건물 종류에 맞는 현장(30×20 격자)을 만든다. 교통사고만 교차로에서 일어난다. 이 시점부터 불은 번지고 부상자는 악화된다.
2. **신고**: 신고자는 침착함·공황·상황 파악 미흡·일부만 목격·부정확한 확신 중 한 성향을 갖고, 사건의 일부만 혹은 틀리게 안다. 위치를 제대로 아는 신고자는 주소와 건물 이름을 말하고, 그렇지 않으면 옆 교차로를 대기도 한다. 접수 AI는 현재 가설에 따라 다음 질문을 고르고, 지혈·가슴 압박·대피 같은 안내를 한다. 신고자가 따르면 현장 상태가 실제로 바뀐다.
3. **분석**: 진술의 키워드와 신뢰도, 그리고 신고된 곳이 지도에서 어떤 건물인지(하천이면 수난, 교차로면 교통사고가 더 그럴듯하다)로 유형 확률과 위험도를 계산한다. 입력이 틀리면 결론도 틀린다. 추가 신고나 현장 보고가 오면 다시 평가한다.
4. **배정**: 필요한 능력별로 `적합도 − 도착 시간 − 피로 − 장비 상태 − 예비 전력 손실` 점수가 가장 높은 부대를 보낸다. 가용 부대가 없으면 대기열에 올리고, 긴급도 차이가 크면 다른 사건으로 가던 부대를 돌린다.
5. **이동**: 도로 그래프 위를 달려 가장 가까운 교차로에 닿은 뒤, 그 건물 앞 길가까지 마저 가서 선다. 정체와 통제를 반영하고 교차로마다 경로를 다시 본다. 신고 위치가 틀렸으면 엉뚱한 곳에 먼저 도착한다.
6. **현장**: 먼저 도착한 부대의 선임이 지휘를 맡고 현장 평가를 한 뒤 작업 목록을 만든다. 대원은 인지 → 믿음 갱신 → 목표 선택 → 실행 → 보고 → 재계획을 반복한다.
7. **종료**: 지휘관이 자신의 믿음으로 종료를 선언한다. 판정은 엔진의 진실로 내리므로 지휘관이 놓친 구조 대상도 보고서에 드러난다.

### 설계에서 정한 것들

- **정보 격리**: 대원은 시야 안에서 본 것과 무전·대면으로 들은 것만 안다. 이동 경로도 믿음으로 계획하므로, 잠긴 문이나 잔해는 부딪혀 본 뒤에야 알고 우회·제거·포기 중에서 다시 고른다.
- **실패는 상태에서 나온다**: 연기로 줄어든 시야 때문에 방 구석의 구조 대상을 지나치고, 출동 전부터 상태가 나빴던 펌프가 방수 중에 고장 나고, 통제되지 않은 차로에서 2차 사고가 난다. 난수는 사건 생성과 사격 판정 등 일부에만 쓴다.
- **실내 전술**: 용의자는 바라보는 방향만 본다. 지휘관은 진입을 결정할 때 자기가 아는 용의자의 위치와 마지막으로 본 방향으로 출입구를 고른다(등지고 있는 쪽 > 벽에 가린 쪽 > 가까운 쪽). 총기를 든 경찰이 4명 이상이면(폭발물 처리 요원은 세지 않는다) 두 문으로 나뉘어 동시에 들어가고, 방패수는 언제나 주 출입구로 간다. 닫힌 문 뒤의 방은 문 앞에 모였다가 섬광탄을 던져 넣고 들어간다. 섬광탄은 벽을 넘지 못한다. 인질이 곁에 있으면 사격을 삼가고 다가가 덮치며, 섬광탄 없이 방에 들어가면 놀란 인질범이 인질을 쏠 수 있다.
- **용의자의 대응**: 사격을 받으면 대원에게 보이지 않는 엄폐 위치로 옮기고, 인질범은 진입이 시작되면 인질을 끌고 먼 방으로 물러나며, 총격범은 대원이 보이지 않는 동안 다른 사람을 찾아다닌다. 가구를 낀 용의자는 맞히기 어렵다.
- **도시**: `src/sim/cityPlan.ts` 가 설계도다. 교차로 78곳의 자리와 도로 50개가 지나는 순서, 해안선·강·철길·산, 동네 18곳의 성격(어떤 건물이 얼마나 섞이는가), 손으로 자리를 정한 건물 60여 곳을 적어 두었다. 생성기는 이 설계도를 읽어 큰 도로가 둘러싼 블록을 찾고, 넓은 블록 안에 이면 도로를 내고(교차로가 173곳으로 늘어난다), 도로를 따라 길 양쪽에 건물을 채우고, 긴 길에서는 막다른 골목을 내고, 블록 안쪽에는 뒷집·아파트 동·공장을 놓는다. 건물을 놓을 때마다 도로·골목·철길·물·다른 건물과의 거리를 정확히 계산해 겹치는 자리는 버린다. 동네의 경계에서는 두 동네의 건물이 섞인다. 도시는 고정이므로 교대가 바뀌어도 같은 지도다. 어떤 유형의 사건이 어떤 건물에서 나는지도 같은 파일의 표에 있다.
- **부대**: 종류마다 능력이 다르고(사다리차는 용수가 많고, 특공대는 섬광탄과 방호가 좋고, 화학 구조대는 누출 조치가 빠르다), 구조정은 바닷가의 수난 사고에만 나간다. 관제는 지금처럼 **부대 수** 단위로 보내고, 능력이 기준을 넘는 부대에는 그 일을 할 장비를 든 대원이 반드시 있다(테스트가 지킨다).
- **편성과 장비**: 편성표(`src/sim/crews.ts`)가 부대 종류마다 자리 순서와 역할을 정한다. 0번 자리가 부대장이고, 부대 규모 손잡이 1·2 와 인근 도시 지원 부대는 최소 인원으로 나온다. 대원의 능력은 역할의 식으로, 맡을 수 있는 일·방호·작업 속도는 든 장비로 정해진다(부서가 아니다). 일 하나에 붙는 사람 수는 그대로라, 사람이 늘면 다른 일을 맡는다 — 기관원은 소화전 연결과 펌프를, 저격·관측수는 봉쇄를, 구급 운전원은 탑승과 이송을 먼저 맡는다. 장비가 더 좋은 대원이 늦게 닿으면 맨손으로 붙들고 있던 구출을 넘겨받는다. 숨은 고장은 진실이라 배정과 관제는 모른다 — 그 장비로 효과를 내려는 순간에 드러나 기록이 남고, 그때부터 조직이 안다.
- **헬기**: 관제는 헬기 종류마다 맡는 수요가 다르다(경찰 헬기는 수색 수요만, 소방 헬기는 수색·구조만, 의료 헬기는 낮의 구급 수요만). 상공에 머무는 헬기는 대원이 내리지 않는 현장 부대다 — 공중 관측자는 현장 대원 목록 밖에 있어 용의자의 표적도 지휘관도 되지 않고, 하늘에서 본 것을 무전으로 알릴 뿐 사람을 움직이지는 않는다. 관측자의 판단은 자기 믿음과 지휘관의 작업판만 읽는다. 헬기는 환자를 한 명만 싣고(위중 환자를 헬기에 먼저 싣는다), 할 일이 없으면 스스로 "상공 임무 종료"를 알리고 돌아간다. 헬기만 닿았던 현장은 그 헬기의 보고로 끝나거나 관제가 지상 부대를 다시 찾는다.
- **현장 배치**: 건물 종류가 평면의 틀을 정한다(작은 집은 단층, 아파트·사무용 건물은 복도형에 2층이 많고, 시장·창고·격납고는 홀형, 은행에서 난 무장 사건은 은행 로비). 방의 수·크기·문 위치는 사건마다 새로 만든다. AI는 좌표가 아니라 자기가 본 구역과 출입구로 판단한다.
- **물**: 수난 사고의 사람은 물살에 떠내려간다. 대원은 물에 들어가지 않고 가까운 물가에서 구조 줄을 던져 끌어낸다(구조 로프·구명환을 든 대원이 빠르다). 소방 헬기가 상공에 있으면 호이스트로도 끌어올린다 — 둘 가운데 먼저 끝나는 쪽이 구한다. 늦으면 화면 밖으로 떠내려가 잃는다.
- **병원**: 구급차가 한꺼번에 몰리면 응급실 인계가 밀리고, 그만큼 구급차가 늦게 돌아온다.
- **AI 구조**: 명세의 Utility AI + Behavior Tree + HTN 조합 대신, 대원은 Utility 목표 선택과 임무별 단계 실행기, 지휘관은 믿음에서 작업을 분해하는 규칙으로 구현했다.
- **층**: 2층 건물은 두 층의 평면을 같은 격자에 나란히 놓고 계단 칸끼리 잇는다. 대원과 대피자는 계단을 오르내리는 데 시간이 걸리고, 불과 연기도 계단을 타고 번진다.
- **위험한 건물**: 불이 났거나, 가스가 찼거나, 무너질 수 있는 건물 안에는 공기호흡기를 멘 대원(소방·구조·화학 구조대, 항공 구조대원)만 들어가고, 공기가 45초 아래로 떨어진 대원은 통을 바꾸기 전에는 새로 들어가지 않는다. 구급은 밖에서 처치와 이송을 맡고, 경찰은 가스 누출 현장의 출입구를 지켜 주변 시민이 다가오지 못하게 한다(지키지 않은 출입구로는 시민이 다가와 가스를 마신다).
- **교통과 정보**: 관제와 부대는 알려진 도로 상태만 안다. 공사와 행사는 미리 알려지지만 낙하물과 불법 주차는 부대가 그 앞에 가서야 알게 되고, 알린 뒤에는 다른 부대의 경로도 그 길을 피한다. 길을 막는 것은 다른 길이 남아 있을 때만 놓이고, 하나 남은 길을 막게 된 장애물은 바로 치워진다.
- **대형 사고와 재난**: 대형 사고는 교대마다 정해진 확률(사건 심각도 손잡이)로 많아야 한 번 일어난다. 재난은 교대 전체의 조건이다. 둘 다 평소의 사건 추첨과는 별개의 난수 흐름을 써서, 재난이 없는 교대의 결과는 재난 기능이 있든 없든 같다.
- **파손**: 창은 총알이 지나가거나 폭발·열이 닿으면 깨지고, 엄폐 가구는 빗나간 총알을 대신 맞다가 부서져 바닥이 된다(엄폐가 사라지고 길이 열린다). 파손은 따로 가른 난수를 써서 사격의 명중 판정을 바꾸지 않는다.
- **종료 보장**: 재시도 보류 시간, 현장별 한계 시간(300~470초, 다수 사상자 사고는 570초, 대형 사고는 그보다 길다), 교대 종료 후 7분 상한으로 모든 사건이 반드시 끝난다.
- **저장**: LocalStorage에 설정, 진행 중인 시드·난이도·틱, 최근 교대 12개의 요약을 저장한다. 새로고침하면 같은 조건을 저장된 틱까지 다시 돌려 복원한다.

## 구현된 기능

- **도시와 자원**: 건물과 터 약 1,250곳(종류 69가지)에 이름·주소·진입 지점, 등급이 네 가지인 도로와 이면 도로 81구간(교차로 173곳), 골목, 강과 다리 5개, 바다·해수욕장·항구·등대, 산·호수·댐, 철길과 역·건널목 6곳, 공항, 소방서 4곳·경찰서 3곳·병원 2곳·소방항공대·해양구조대, 도로 그래프와 경로 탐색, 교통(혼잡의 밀림·공사·고장 차량·낙하물·불법 주차·행사 인파·열차), 사고 구간 통제, 네 분야 12~22팀·대원 32~75명(특공대·헬기 세 종류·화학 구조대·구조정·폭발물 처리반·사다리차 포함), 부대 종류 14가지의 편성표와 역할 36가지·개인 장비 36가지, 인근 도시 지원.
- **현장 종류**: 단층·2층 건물 화재, 교통사고(승용차 사고·버스 추돌), 산림 수색, 무장 사건(편의점·은행·사무실·창고·주택), 주택 응급 환자(배치 2종), 건물 붕괴(잔해·매몰자·균열부 보강·2차 붕괴), 가스 누출(밸브 차단·가스 확산·폭발·출입구 통제), 수난 사고(하천·다리·표류). 여기에 폭발물이 놓인 건물, 대형 인질극, 폭동, 방화, 도로 위에 선 도주 차량, 비행기 추락 현장(들판의 동체 세 토막), 열차 탈선(건널목의 객차), 다중 추돌, 가스 폭발, 크레인이 쓰러진 공사장, 부두에 댄 배의 화재, 산불(숲과 오두막), 산사태(흙더미에 묻힌 차), 해안 대피(모래밭과 부두). 건물 평면은 사건마다 새로 만들어지고, 가구는 실제 장애물이자 엄폐물이며 부서진다.
- **신고 접수**: 신고자 성향 6종, 질문 선택형 통화, 추가 신고 연결, 통화 중 안내, 장난 전화 낌새 감지, 비긴급 전화, 위치 오인과 정정.
- **분석과 배정**: 유형 확률·위험도·필요 자원, 재평가, 오래 기다린 사건을 앞세우는 대기열, 전환 배정(같은 사건에서 되풀이하지 않음), 중증 응급의 소방 선착 대응, 현장 지원 요청(맡을 사람이 없는 작업의 능력까지), 병원 이송(응급실 인계 대기) 후 재출동.
- **현장 행동**: 현장 평가, 수색, 화재 진압, 급수 연결, 잔해 제거, 문 강제 개방, 구출, 기본·전문 응급 처치, 이송, 구급차 탑승, 교통 통제, 연료 누출 조치, 가스 밸브 차단, 균열부 보강, 구조 줄을 던지는 수난 구조, 폭발물 해체(원격 로봇), 계단 이동, 출입구 봉쇄·통제, 협상, 진입 지점 선택, 두 문 동시 진입, 방 단위 진입, 섬광탄, 테이저, 교전, 검거, 목격자 면담, 도로 정리, 동료 구조, 후퇴, 휴식, 장비 교체, 공기통 교체, 구출 교대. 상공의 헬기는 공중 관측·탐조등·호이스트 인양·공중 물 투하를 한다. 다수 사상자 현장에서는 지휘관이 구급·구조 부대를 더 부른다.
- **문제와 재계획**: 경로 차단 → 우회 또는 제거, 무전 음영 → 이동 후 재보고, 펌프 고장 → 예비 펌프로 교체, 개인 장비 고장 → 다음으로 좋은 장비나 맨손·다른 대원, 공기 부족 → 통 교체, 헬기의 연료·강풍 → 복귀하고 그 수요를 다시 연다, 인원 불일치 → 재수색, 수색 실패 → 범위 재조정, 위치 오류 → 재확인 후 재이동.
- **현장에서 생기는 일**: 배회 실종자가 개울에 빠지거나 넘어지거나 저체온으로 숨어듦, 응급 환자의 급변(실신 → 심정지, 내부 출혈), 오래 눌렸던 사람의 압궤 증후군, 갇힌 승강기 안의 발작, 경찰이 닿기 전 가해자의 이탈, 꺼진 줄 알았던 불이 되살아남(잔불 정리로 찾아 끈다).
- **연쇄**: 총을 든 채 달아난 용의자의 재범이나 도주 차량, 납치범이 숨어든 은신처에서 이어지는 인질극, 잡지 못한 방화범의 다음 불, 사고 구간 통제가 다른 출동의 경로에 미치는 영향, 지진 뒤의 여진.
- **관찰**: 자동 카메라, 현장 자동 확대, 결정적 순간의 자동 감속, 주요 장면 이어 보기, 현장 확대·이동, 관찰자/AI 시점(벽에 가려지는 시야, 아직 모르는 장애물), 다중 현장 창, 되감기와 결정적 순간, 대원별 역할·장비·행동 후보 점수·믿음 목록·인지 범위, 부대 목록의 역할 점, 상공 헬기의 하는 일, 오른쪽 칸의 접히는 신고 통화창(P 키), 속보, 재난 특보 띠, 지도 범례, 소리(합성음).
- **그림**: 바닥 재질·두께 있는 벽·가구·수목을 한 번만 그려 두는 고정 층, 깨진 창과 닳거나 부서진 가구, 임무·역할·든 장비에 따라 복장과 자세가 바뀌는 인물, 차종별 차량과 도색이 다른 헬기 세 종류, 상공의 헬기(그림자·호이스트 줄·물 바구니·물 띠·탐조등), 화염·연기·물줄기·유리와 가구 파편, 손전등·경광등·가로등 조명, 비·안개·밤. 지도의 부대·시설·장애물은 그림 기호로 그린다(글자 표식 없음).
- **결과**: 성공·부분 성공·대응 지연·미해결·실패 판정, 원인 연결 이벤트 기록, 사건별 원인 설명이 담긴 종료 보고서.
- **조건**: 시드, 난이도 손잡이 7개와 프리셋 4개, 재난(없음·무작위·다섯 종류).
- **도구**: 헤드리스 실행기(시나리오 강제·재난 지정·시나리오별 결과 표), 측정 도구(인과 연쇄 깊이·시스템 간 영향·재계획·대체 방법·행동 다양성·자원 경쟁·멈춘 시간·결과 다양성 — `npm run sweep -- 40 --metrics`), 자동 테스트, 커밋 전 관문(교착 후보 0 포함), 화면 자동 검사(`npm run ui-check`), 묶음별 구현 설계서.

## 미구현과 알려진 문제

- **경험치·숙련도 변화 없음**: 대원의 경험 수치는 누적되지만 능력치에 반영되지 않고 교대 사이에 저장되지도 않는다.
- **없는 것**: 3층 이상 건물, 무장 사건의 2층 건물, 보트·잠수를 쓰는 수난 구조, 병상 수 같은 병원 수용 한계(지금은 인계 대기 시간만 있다), 예산, 장기 성장.
- **붕괴 현장의 탐지 장비는 발견 보정뿐이다**: 탐지 장비(음향·영상)는 이제 구조 공작차라는 부대가 아니라 그것을 든 대원(구조 팀장·탐지 구조대원)의 것이고, 고장 나면 효과가 없으며 처음 살필 때 고장이 드러난다. 그래도 하는 일은 매몰자를 더 멀리서 알아챈다는 보정뿐이다 — 청음기를 대고 듣거나 탐지견을 푸는 행동은 없다.
- **같은 일을 장비에 따라 다른 방법으로 하지는 않는다**: 장비는 맡을 수 있는가와 빠르기만 바꾼다. 구명줄이 없으면 헤엄쳐 구조하기, 보트 구조, 소화기, 비살상탄, 폭파 진입(장약은 들고만 있다) 같은 방법 갈래는 다음 묶음(R2)이다. 대원의 부상·사망 모델(H1), 둘이 들어가고 둘이 남는 짝 규칙과 탄약(R3)도 아직 없다 — 총은 무제한이다.
- **헬기가 뜨는 날의 실종 사건은 거의 다 성공한다**: 보통 60교대에서 실종·조난 성공률이 97%다(R1 전 81%). 경찰 헬기가 열영상으로 현장을 줄지어 훑으면 한 바퀴(80초쯤) 안에 다 찾는다. 관측 거리와 열영상 배율을 절반으로 낮춰 재 보아도 95%였다 — 숫자가 아니라 "훑으면 반드시 보인다"가 원인이라, 줄이려면 나무 밑의 사람이 하늘에서 가려지는 것 같은 새 규칙이 필요하다. 안개 낀 날(시드 60개 가운데 11교대)과 헬기가 다른 사건에 가 있을 때는 예전처럼 걸어서 찾는다.
- **헬기의 한계**: 의료 헬기는 다수 사상자 사고에서 한 명씩 실어 나르며 같은 현장을 네댓 번 오간다(지휘관의 급한 구급 요청마다 적합도가 구급차보다 높다. 낮 교대만 치면 교대당 5.1회, 전체로는 2.8회 — 실어 나른 환자의 12%). 경찰 헬기가 실종 현장 상공에 있는 동안 추격전이 나면 그쪽으로 돌리지 않는다. 헬기만 닿았던 사건은 모두 구해도 '대응 지연'이다(대응 시간은 지상 도착 기준). 상공의 연료 복귀는 드물다(현장이 연료보다 먼저 끝난다). 헬기 소리는 없다.
- **공기통은 보통 난이도에서 거의 문제가 되지 않는다**: 보통 60교대에 "공기 잔량 60초 미만" 2번·교체 2번이다. 어려움(73번)·극한(286번)과 부대 규모 1 에서 드러난다. 다쳐서 물러난 대원이 연기 낀 대기 지점에 오래 있으면 통이 빈다(대기 지점을 옮기는 규칙이 없다). 드러나는 장비 고장은 보통에서 교대당 0.17건이다(숨은 고장은 교대당 0.8건).
- **부대 규모 1·2(최소 인원)의 화재는 더 어렵다**: 펌프차·사다리차의 관창이 하나뿐이다. 관창을 든 사람만 물을 쏘므로 관창수의 지구력이 먼저 바닥나고, 관창을 넘겨받는 규칙은 없다.
- **같은 지시의 되풀이가 늘었다**: 대원이 늘어 지휘관의 믿음이 더 자주 뒤집힌다(진압 작업이 만들어졌다 끝나기를 되풀이). 무전 음영 구역에서 대기 중인 대원에게 같은 지시를 4.8초마다 아홉 번까지 다시 낸 교대가 있다(측정 지표 `repeat max` 5 → 9, 관문 아님). 교통 통제를 마친 보고가 묶음 보고를 기다리는 사이 같은 통제를 다시 지시하는 일도 그대로다.
- **유형별 난도 차이**: 보통 기준 성공률이 화재 71%, 무장 77%, 건물 붕괴 78%, 수난 사고 78%, 가스 누출 82%, 교통사고 83%, 응급 환자 83%, 실종·조난 97%다. 화재가 여전히 가장 어렵고, 실종·조난은 위 항목의 까닭으로 예전의 목표 범위(62~84%)를 벗어나 있다.
- **생활 사건은 쉽다**: 쓰러진 나무·맨홀 추락은 60교대에서 모두 성공으로 끝났다. 승강기 갇힘에는 갇힌 사람의 발작이, 가정 폭력·난동에는 경찰이 닿기 전 가해자의 이탈이 생겨 가끔 결과가 갈린다. 침입 절도는 셋 중 하나꼴로 용의자를 놓친다.
- **아직 없는 사건**: 다리 위의 위기자, 동물 출몰, 끊어진 전선, 금고털이는 넣지 못했다.
- **추격전은 단순하다**: 도주 차량은 교차로마다 길을 고를 뿐 건물 사이로 숨거나 차를 바꿔 타지 않는다. 달아나는 차는 건널목 차단기를 무시한다.
- **막다른 골목은 지도와 주소에만 있다**: 차량이 다니는 도로망은 고속화 도로·간선·일반·이면 도로다. 막다른 골목 안쪽 건물에 사건이 나면 차량은 가장 가까운 길가에 선다.
- **현장 그림은 지도의 건물 외곽과 같지 않다**: 현장은 건물 종류에 맞춰 30×20 격자에 새로 만든다. 지도에서 길쭉한 아파트 동이 현장에서는 다른 비율로 보일 수 있다.
- **공공 시설에서는 사건이 나지 않는다**: 소방서·경찰서·병원·시청·학교·물류 터미널은 지도에 있지만 사건 장소로는 쓰지 않는다.
- **최초 배정이 보수적이다**: 사건의 33%에서 현장 지휘관이 추가 지원을 요청한다.
- **높은 난이도에서는 한계 시간으로 끝나는 사건이 있다**: 추격전에서 놓친 것을 빼면 시드 60개에서 쉬움 0건, 보통 848건 중 1건(총격범 사건 — 결과는 성공), 어려움 1,104건 중 4건, 극한 1,394건 중 10건(0.7%). 어려움의 4건과 극한의 8건은 모두 화재다(대부분 소실률 47~74%의 큰 불 — 펌프 고장·물 부족 속에서 끄다가 한계에 닿는다. R1 전에는 어려움 1건·극한 6건). 극한의 나머지 둘은 구급차가 모자라 경상자를 안전 구역에 둔 채 끝난 실종 사건과, 안개 낀 날 아무도 가지 못한 오인 신고다.
- **헤드리스 실행 시간**: 교대 하나를 돌리는 데 보통 약 280ms(공유 4코어 기계, 같은 조건에서 R1 전 약 200ms — 현장의 대원이 1.9배라 1.4배 느려졌다), 관문 `npm run check` 는 4분쯤 걸린다(테스트만 3분 남짓). 남은 비용은 첫 교대들의 JIT 예열, 도시 생성(약 450ms, 한 번), 판단 로직이다.
- **정보 격리의 예외 세 가지**: 지휘관은 7초마다 건물 밖에서 화염을 벽 너머로 관찰한다. 이미 발견한 구조 대상이나 용의자가 움직일 때 대원은 그 현재 위치를 따라간다. 스스로 대피한 사람이 안전 구역에 도착하면 현장 무전망에 자동으로 알려진다.
- **진입 계획은 문 단위다**: 지휘관은 건물 출입구를 최대 두 곳 고르고, 방은 진입조가 용의자를 쫓아가며 문 앞 대기 → 섬광탄 → 진입을 한다. 건물 전체를 방 순서대로 훑는 계획은 없다.
- **현장 화면의 겹침**: 대기 지점에 열 명 넘게 모이므로 같은 이름표("대기")는 하나로 모아 그리고, 가까이 뜬 두 헬기는 한 대를 옆으로 비켜 그린다(시뮬레이션의 자리와 세 칸까지 다를 수 있다). 사상자 이름표끼리의 겹침은 그대로다. 13 화소의 역할 점에서 조종사·의사 기호는 세부가 뭉개진다.
- **프레임 속도**: 그래픽 가속이 없는 헤드리스 브라우저에서 도시 지도 60FPS, 보통 현장 44~58FPS, 불과 안개가 겹친 큰 현장 33FPS였다. 가속이 되는 일반 브라우저에서는 재지 못했다.
- **소리는 귀로 확인하지 못했다**: 헤드리스 브라우저에서 오류 없이 동작하고 초당 소리 수가 상한 안에 드는 것만 확인했다. 음색과 음량 균형은 직접 들어 보고 조정해야 한다(교전 소리의 체크리스트는 `docs/specs/G5-combat-fx.md` 8.4절).
- **교전 연출의 한계**: 탄 한 발은 쏜 자리에서 겨눈 점까지의 한 선분이라, 그려진 선과 실제로 깨진 창·박힌 엄폐물이 언제나 같다(사용자 결정으로 맞췄다). 다만 문틀 옆에 선 대원의 빗나간 탄은 시야 판정 탓에 문틀에 연달아 박혀 보일 수 있다. 진입 뒤 섬광탄은 그림·소리가 0.12~0.46초 늦다(무력화는 그 틱에 걸린다). 되감기하면 탄흔·그을음이 사라진다. 고해상도(dpr 2) 화면에서는 섬광·진입 순간에 프레임 속도가 약 30% 떨어진다(헤드리스 측정, dpr 1 에서는 약 4%).
- **데스크톱 전용**: 가로 1280px 이상을 기준으로 만들었고 터치 조작은 지원하지 않는다. 글꼴은 시스템의 한글 글꼴을 쓴다.
- **재현 범위**: 같은 빌드, 같은 브라우저 엔진에서의 재현을 보장한다.
