## 설계서와 다르게 한 곳

- 1. readOrg reads storage first, then the in-window copy orgMem; the spec says to use orgMem whenever it exists. If the same id is in both, the one with the higher shift wins. Reading the copy first would hide another window having advanced the org.
- 2. URL-fixed runs also write ar.input.v1 (carry null, write false), and '?org=' on its own counts as URL-fixed ('?org=continue' = use the saved org, don't save). Without this, a restore could pair with a stale input from an earlier shift.
- 3. The report shows '다음 교대 (이어서)' only when this shift actually saved the org. Otherwise the old '새 교대 시작' sits in that slot.
- 4. '같은 시드 재실행' (top bar and report) and the difficulty panel's same-seed start both run in replay mode: same carry, no save.
- 5. CarrySummary.grown counts outgoing crew with cumulative dSkill ≥ GROWN_MIN (0.01). The stage-2 summary wording '숙련이 오른 대원 n명' (any increase) is left as is, because changing it would change carried-over hashes. The two counts therefore differ.
- 6. carryNext is built only when sim.ended. tests/methods.test.ts calls buildReport on unfinished shifts, and makeCarryover throws on those.
- 7. The two new summary lines go at the very end, after the helicopter line. The effect line appears only when there are effects; the next-shift line always appears.
- 8. The effect line's short phrases are fixed: short-crew incidents, relief crew, units back from maintenance, reopened repair roads, incidents in damaged buildings, flashbangs issued short. Call signs and incident codes are capped at six, then '외 n'.
- 9. In the analysis sentence, n = deployable crew (crews.fieldCrew members not off), the same unit crewReady uses. It goes right after the response-time line.
- 10. The difficulty modal puts the disaster row and the org row side by side (.cond-rows) and is widened from 820 to 960px. At 820px the start buttons were pushed out of the modal at 1600x900. Clear uses an inline '지우기 · 그대로' confirm.
- 11. Map: at large scale the repair cone sits top-left inside the roof, because the building name label sits in the centre, and stays upright. At small scale glyphs don't rotate with the building. Line widths are in screen pixels. A ruin with no X6 mark uses paintRoofHole('major', 0.3).
- 12. Scene soot: tiles burnt from the start are already drawn by fx.ts. staticLayer only adds faint radial floor smudges and thin streaks along walls, and staticSig includes round(soot·100).
- 13. Off-crew display: dim role dot with a diagonal stroke, dim crew-chief chip with a horizontal stroke, no health arc. Relief crew get a white dot at the top right of the role dot. .cchip.relief is kept but cannot occur.
- 14. ui-check 9: ui-check-ref.ts dumpCarry makes a state from a 60s shift with two crew off for one shift, stores it, and opens /?seed=S3&org=continue. It checks the org chip, snap().off == number of off dots, and that the hash equals the headless run with the same carry.
