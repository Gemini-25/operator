## 설계와 다르게 한 곳

- The 'hos' fact band is not hidden by distance; only dead is restricted to 2 tiles. The spec rule (§4.3: beyond 3 tiles, band = 2 if down else 1) would make the commander see unhurt arrested suspects as band 1 from afar. That issues treatSuspect, the near report says 0, the far report says 1 again: an endless loop. I made it work like casFact (visible band, capped at 2). Also, an arrested suspect who is down shows the text '검거 · 쓰러짐'.
- Suspect bleed ×0.6 applies when treated AND (arrested or down). That is my reading of §2.6 "처치를 받고 안전 구역에 있거나 검거되어 있으면", since suspects have no safe zone.
- Per-tick fire, smoke and gas damage to suspects lives in rules/injury.ts hostileHazards (the spec gives no location). Smoke has no threshold, same as for casualties, so rioters near burning objects take smoke damage (about 14 on average).
- hurtHostile also returns early for escaped suspects and those whose where is not 'scene' (the spec lists only dead and closed).
- When choosing a vehicle for a suspect, waiting injured mates count as band 2 if they were ever down or are band ≥2.
- The commander never calls EMS just for an injured suspect. The spec does not say to; the only path is the mass-casualty recount.
- Loading text includes a particle: '○○을 ${호출부호}에 태워 병원으로.' (the spec has '○○ ${호출부호}에 …').
- The taser's 'electric 2' is applied as a one-time hit, which adds a tiny bleed.
- settleHostile is exported so the tickHostiles safety net reuses it. When a suspect goes down, the down log event is linked as the ev of any injury that had none, so a later death traces back to it.
- Stage 5 fix: a dead treatSuspect target is approached before reporting, and TS_MAX_DONE = 4 caps items per suspect. Neither is in the spec.
- The §2.6 'time 4.5 + …' is progress units in the shared treat formula. Police medical skill is low (rate floor 0.1/s), so police care of a critical suspect takes about 85 s. Left as is.
- Martyr summary format is '순직: ○○ 대원(호출부호, 사건 03 대형 인질극).' (incident code plus scenario name). The spec's 'F-03 화재' code format does not exist in the current code.
- ShiftReport respondersHurt[].hospital is true when care is set at all (aboard or hospital).
- The report row adds a '쓰러짐' item. The 용의자 사상 tile shows the hurt count large and '다침 · 사망 m' small.
- Casualty death sentences use deathCause, matching the death log line, rather than mainCause.
- Name not in the spec: SELF_HARM_HIT [22, 38].
