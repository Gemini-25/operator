## 알려진 문제 · 다음 작업자가 알아야 할 것

- (중요) tests/sim.test.ts '허위·오인 신고는 인명 피해 없이 확인 출동으로 끝난다' 는 false·prank 사건의 casualties.length === 0 을 본다. 본문대로 만든 medical/false 의 잠든 사람은 구조 대상이라 보통 S0~S13 에 medical/false 가 한 건이라도 생기면 깨진다(지금은 없음 — 비응급 아홉 건 모두 구조 대상 0). §9.2 의 고칠 수 있는 네 곳 밖이고 시드 범위를 넓혀도 못 피한다. 단계 4a 이후 daily 줄이 비응급 줄 앞에 들어오면 추첨 위치가 바뀌어 일어날 공산이 크다(medical/false 교대당 ≈0.11건 → 14교대에 한 건 이상 ≈78%). 고르는 길: ① 잠든 사람을 fixture skin 'sleeper' + evid sleeper 로 바꿈 ② 설계자가 시험 조건을 '띠 0 이 아닌 구조 대상'으로 허락
